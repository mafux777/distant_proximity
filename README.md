# distant_proximity

Materials for practical AI training workshops by Matthias Funke ([distantproximity.co.uk](https://distantproximity.co.uk)).

## Contents

- [`second-brain-starter/`](second-brain-starter/) — Onboarding interview, rulebook, and daily briefing starter kit for the *Build a Second Brain* workshop (Claude, ChatGPT, Gemini, Antigravity).
- [`invoice-cleanup-demo/`](invoice-cleanup-demo/) — Deterministic Python + `openpyxl` demo showing live Excel formulas, reconciliation checks, human-review logging, and native conditional formatting from a messy invoice CSV.
- [`sample_emails_trips.json`](sample_emails_trips.json) — Synthetic email dataset used in the *Agents, Demystified* introductory workshop.
